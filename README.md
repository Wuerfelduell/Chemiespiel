# Chemiespiel
Ein Spiel was beim chemie lernen hilft

Multiple-Choice-Quiz zum **Fragenkatalog CHE1VO/ACA1VO_bb (WS 26/27)**:

- alle 58 Fragen aus dem Katalog im Originalwortlaut, keine neuen Fragen
- je 4 Antwortmöglichkeiten (zufällig gemischt); die richtige Antwort stammt aus dem Skriptum
- nach jeder Antwort: ausführliche Musterantwort + Seitenangabe im Skriptum
- **Pool für sichere Fragen:** eine Frage ist sicher, wenn sie 3× hintereinander richtig beantwortet wurde; ein Fehler macht sie wieder unsicher
- Button **„Unsichere Fragen üben“** – spielt nur die noch nicht sicheren Fragen (neue/falsche zuerst)
- Übersicht aller 58 Fragen mit Fortschritt (0–3× richtig in Folge)
- Filter nach Themen, 10/20 zufällige Fragen, nur unsichere oder nur sichere Fragen
- falsch beantwortete Fragen direkt wiederholen; Fortschritt wird lokal im Browser gespeichert
- Tastatur: `1`–`4` bzw. `A`–`D` zum Antworten, `Enter` für die nächste Frage

## Starten

`index.html` im Browser öffnen – oder über GitHub Pages
(Settings → Pages → „Deploy from a branch“, Ordner `/ (root)`).

## Dateien

- `index.html` – das Spiel
- `fragen.js` – alle Fragen, Antworten, Erklärungen und Skriptum-Seiten
